# 🎬 Video Frame Extractor Pro

A powerful, production-ready web application that extracts frames from videos, generates AI-powered subtitles in 270+ languages, creates structured documents (PDF/PPTX), and helps students and MSMEs overcome language barriers. Built with **Streamlit**, **OpenCV**, and **OpenAI Whisper**.

## 📖 Overview

Video Frame Extractor Pro is a web-based tool that helps students, professionals, and MSMEs extract frames from videos, generate accurate subtitles in 270+ languages, and create structured documents for better comprehension. Whether you're an international student struggling with accents, a content creator needing multilingual content, or an MSME looking to expand your reach, this app provides everything you need.

**✨ New!** Now includes **AI-powered video-to-text conversion**, **multilingual translation**, and **document generation** - turn any video into structured content in your preferred language!

**No database, no user accounts, no permanent storage** - just upload, process, download, and go.

## ⚙️ How It Works

### Video-to-Text Flow
User uploads video
↓
App extracts audio using ffmpeg
↓
OpenAI Whisper transcribes audio
↓
Text simplified (optional)
↓
Translated to target language (270+ options)
↓
Content structured into sections
↓
Multiple outputs generated:
• SRT Subtitles
• TXT Transcript
• PDF Document
• PPTX Presentation
• MP3 Audio (if requested)
↓
User downloads desired formats
↓
ALL temporary files automatically deleted

text

### Frame Extraction Flow
User uploads video (or provides URL)
↓
Video saved to temporary storage
↓
App displays video player and information
↓
User watches video and selects start/end times
↓
User configures extraction settings in sidebar
↓
Frames extracted based on selected time range
↓
Frames compressed into ZIP archive
↓
User downloads ZIP file
↓
ALL temporary files automatically deleted

## 💻 Installation

### Local Development
```bash
# Clone the repository
git clone https://github.com/NeuralBishal/video-frame-extractor.git
cd video-frame-extractor

# Create conda environment (recommended)
conda create -n video_extractor python=3.10
conda activate video_extractor

# Install dependencies
pip install -r requirements.txt

# Install ffmpeg (required for audio extraction)
# On macOS:
brew install ffmpeg
# On Ubuntu:
sudo apt-get install ffmpeg
# On Windows (with conda):
conda install -c conda-forge ffmpeg

# Run the app
streamlit run app.py

# Open browser to http://localhost:8501
GPU Acceleration (Optional)
bash
# For NVIDIA GPUs (RTX 30xx series recommended)

Known Issues

Exotic codecs: May fail to open

Transcription accuracy: Depends on audio quality

Variable framerate: Estimate may be inaccurate

gTTS limitations: Some languages may use English fallback
